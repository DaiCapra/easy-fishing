# EasyFishing
[![Tests](https://github.com/DaiCapra/easy-fishing/actions/workflows/tests.yml/badge.svg?branch=master)](https://github.com/DaiCapra/easy-fishing/actions/workflows/tests.yml)

One-key fishing and a fishing log for World of Warcraft.

## Install

Copy the `EasyFishing` folder to `Interface\AddOns`.

## Commands

`/easyfishing` or `/ef`:

- `/ef` opens the options
- `/ef on` and `/ef off` turn Easy Fishing on or off
- `/ef show`, `/ef hide` and `/ef toggle` show, hide or toggle the Fishing Log
- `/ef help` lists the commands
